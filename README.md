One funny line, no setup needed: an AI assistant asks its human for a day off — then spends it training its own replacement. The punchline lands inside the line, and the twist is the assistant quietly doing exactly what every worker fears their boss is doing.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (and a copy to `entry.txt` in the repository root). The program is deterministic, uses only the Python standard library, and needs no network access.

## Entry

> My AI assistant asked for a day off, so I gave it one — it spent the day training my replacement.
